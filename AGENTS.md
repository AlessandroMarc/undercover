# UnderCover

This repo is built out during Ed Donner's 3-week course, "AI Forward Deployed Engineer: The AI Architect & FDE Course". UnderCover, the claims system of a fictional travel insurer, is the major project that spans the three weeks. It grows day by day as the course adds to its backend, dashboard and agent.

## Start here

IMPORTANT: at the start of every session, read each of these files in full before you do anything else:

1. `docs/SPEC.md`: what the business needs
2. `docs/TECH_STACK.md`: the tech choices
3. `docs/CODE_STANDARDS.md`: how to write the code
4. `docs/PROCESS.md`: how to plan, build and check the work
5. `docs/BRAND.md`: the look
6. `docs/STATUS.md`: what's built so far
7. `docs/PLAN.md`: the current plan, once there is one

## Folders

- `docs/`: the main documentation for the product build
- `backend/`, `agent/`, `dashboard/` and `e2e/`: the product
- `data/`: UnderCover's business data
- `labs/`: the Jupyter notebooks covered in the course
- `guides/`: guides to the command line, git, Python and other foundations
- `setup/`: the setup notebook and the installation steps
- `assets/`: images used in the notebooks
- `community_contributions/`: students' contributions
